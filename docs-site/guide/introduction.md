# 平台概述

**随机舞蹈中文站开放平台**（Random Dance Chinese Site Open Platform）是一套可独立部署的活动报名与歌单投稿管理平台，从 `apps.randomdance.cn` 活动运营平台复刻而来，去除了所有 WordPress 依赖与积分系统，采用独立的用户名 / UID 体系与本地 JWT 鉴权，可开源或交付第三方主办方使用。

## 核心功能

| 模块 | 说明 |
|------|------|
| **路演报名** | 用户提交表演曲目、成员与联系方式，管理员审核与 Excel 导出 |
| **路演选位**（新增） | 场次开放选位通道后，用户实时抢位、幂等取消；管理端可视化编排演出顺序与位次 |
| **随舞歌单投稿** | 用户从曲库选择或添加自定义歌曲投稿，管理员审核、统计与 Excel 导出 |
| **场次管理** | 管理员创建、编辑、取消、删除活动场次，并配置选位参数 |
| **用户系统** | 本地注册 / 登录、JWT 鉴权、角色管理（管理员 / 普通用户） |
| **上传 / 对象存储**（新增） | 本地磁盘与火山引擎 TOS 对象存储自动切换，支持预签名直传与私有读签名 |
| **管理后台** | 仪表盘、报名管理、投稿管理、歌曲库、用户管理、系统日志、客户端事件、云端配置 |
| **音源服务** | 复用外部 FastAPI 音源服务进行歌曲查询与播放（经 Nginx 代理） |

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 19 + TypeScript + Ant Design 6 + Vite 8 |
| 后端 | NestJS 11 + TypeORM + MySQL |
| 鉴权 | 本地 JWT（用户名 / 密码注册登录，`passport-jwt` + `bcryptjs`） |
| 对象存储 | 本地磁盘 / 火山引擎 TOS（`@volcengine/tos-sdk`，可切换） |
| 部署 | Nginx + PM2 |
| 音源 | FastAPI（外部服务，通过 Nginx 代理） |
| 文档 | VitePress 静态站点（本站） |

::: tip 数据库自动同步
后端 `app.module.ts` 使用显式 `entities[]` 数组并开启 `synchronize: true`，实体变更会自动同步表结构，无需手写迁移脚本。生产环境上线前建议先备份数据库。
:::

## 与原平台（apps.randomdance.cn）的差异

| 方面 | 原平台 | 开放平台 |
|------|--------|---------|
| 用户系统 | WordPress JWT | 本地用户名 / 密码 + JWT |
| 积分系统 | WordPress 积分 | 无 |
| 支付功能 | 支付宝 / 微信支付 | 无 |
| 直拍预约 | 完整直拍流程 | 无 |
| 短信 / 微信通知 | 阿里云短信 / 微信服务通知 | 无 |
| 实名认证 | 三要素核验 | 无 |
| 音源服务 | FastAPI | 复用同一 FastAPI |
| 核心功能 | 路演报名 + 歌单投稿 | 路演报名 + 歌单投稿 ✅ |
| 部署方式 | 绑定 WordPress | 独立部署 |

## 开源说明

本平台设计为可独立部署的开源项目，不依赖任何第三方用户系统。第三方主办方只需配置自己的 MySQL 数据库与 Node.js 运行环境即可使用。采用 MIT 许可发布。
